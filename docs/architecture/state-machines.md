# State machines

## Request lifecycle

The canonical request lifecycle is defined in `src/edge_tlm/state_machine.py`. The model cannot skip capability, policy, provider, plan, and validation states.

## Model artifact lifecycle

```text
DISCOVERED
→ SOURCE_BOUND
→ TERMS_CLASSIFIED
→ HUMAN_ACCEPTANCE_REQUIRED | TERMS_ADMITTED
→ DOWNLOADED
→ DIGEST_VERIFIED
→ CONVERSION_REQUIRED | RUNTIME_READY
→ QUALITY_PARITY_TESTED
→ DEVICE_TESTED
→ RELEASE_CANDIDATE
→ ACTIVE
→ ROLLED_BACK | RETIRED
```

## Skill lifecycle

```text
METADATA_DISCOVERED
→ SOURCE_AND_REVISION_BOUND
→ INTEGRITY_VERIFIED
→ PERMISSIONS_CLASSIFIED
→ SANDBOX_PROFILE_SELECTED
→ METADATA_INDEXED
→ REQUEST_MATCHED
→ DETAILED_INSTRUCTIONS_LOADED
→ TOOL_PROPOSAL_VALIDATED
→ USER_CONFIRMATION_REQUIRED | EXECUTION_ADMITTED
→ EXECUTED
→ RESULT_VALIDATED
→ UNLOADED
```

## Evidence lifecycle

```text
SOURCE_STATEMENT
→ CORROBORATED | CONFLICTED | SUPERSEDED
→ IMPLEMENTED_UNVERIFIED
→ VERIFIED_STATIC
→ VERIFIED_LOCAL
→ VERIFIED_LIVE
```

No state can be inferred from a cheaper lane.
