## Material deltas found

1. **LICENSE_DELTA** — the initial architecture grouped permissive runtime repositories and model weights together. The register now separates source code, model weights and SDK/store terms.
2. **COMMERCIAL_USE_DELTA** — FastVLM code and weights were previously treated as one commercial candidate. The official model license is research-only; the weights are rejected as a commercial default.
3. **EVIDENCE_DELTA** — FunctionGemma talk figures were treated as current benchmark facts. The ledger now records current official Mobile Actions figures separately and keeps the talk figures source-packet-gated.
4. **CAPABILITY_DELTA** — system/in-app parameter ranges were treated as invariants. They are now planning hints; device/API capability and policy own selection.
5. **MIGRATION_DELTA** — `.litertlm` was framed as a universal replacement for `.task`. Migration is now explicitly per API/artifact.
6. **SOURCE_IDENTITY_DELTA** — the original article/video/PDF identity is absent. Every card remains indexed, but source-specific claims cannot self-promote.

## What green does not prove

A P0 validator pass does not prove source truth beyond the registered bytes, legal acceptance, commercial permission for model artifacts, current rolling documentation after the retrieval date, native integration, conversion success, model quality, backend selection, privacy, energy, thermal behavior, or merge/release readiness.
